通过读取imu的方式实现雷鸟air4pro的3dof功能
AIR4PRO3DOF 是一款配合雷鸟 Air 4 Pro AR 眼镜使用的
Android 应用。插上眼镜后，手机画面会以 3DoF 头部追踪的
方式悬

【核心功能】
· 3DoF 悬停大屏——画面随头部反向滑动
· 镜像整屏——手机显示什么，眼镜里就投什么
· 截图录像——随时抓拍或录制眼镜画面为 MP4

【使用方法】
1. 手机安装 AIR4PRO3DOF.apk（需 Android 10+、USB-C 显示输出）
2. 用支持数据的全功能线连接眼镜（先退出雷鸟官方 App）
3. 打开 App，点「开始悬停」，按提示授权即可

【注意事项】
· 扩展屏模式建议搭配 Shizuku 使用；无 Shizuku 时仍可用镜像
